## 把长句改成能照做的说明

原材料：

假设发布流程规定：仅在值班人已经确认当晚维护窗口且核对报表没有差异的情况下，执行人才能于窗口内发起切换；若核对报表存在差异，执行人须先把差异交给数据负责人核实，只有数据负责人确认差异为预期结果并在工单注明后才可按前述窗口要求继续，未确认时不得切换；切换后执行人需要观察十分钟，这十分钟内一旦出现连续两次写入失败，就停止新写入并通知值班人，由值班人决定是否回退，执行人不得自行回退；十分钟内没有出现这一触发条件时，可结束本次观察，但这不代表后续运行不会发生问题。

实际输出：

1. 切换前，执行人先确认值班人已确认当晚的维护窗口，并检查核对报表：
   - 报表没有差异：可以在已确认的窗口内发起切换。
   - 报表存在差异：先交给数据负责人核实。只有数据负责人确认差异属于预期结果，并在工单中注明后，才可以在已确认的窗口内发起切换。确认和工单注明未完成前，不得切换。

2. 切换后，执行人观察十分钟。如果这十分钟内出现连续两次写入失败，立即停止新写入并通知值班人。是否回退由值班人决定，执行人不得自行回退。

3. 如果十分钟内未出现连续两次写入失败，可以结束本次观察。观察结束不代表后续运行不会发生问题。

这里的变化是把共同前提、两种分支和失败处理各自放在一起。十分钟、连续两次失败、谁决定回退等条件都保留了。

## 新工具上手说明

这份假设材料还包含内部字段、事件名、本地测试计数、截图数量和维护者开发计划。用户需要的是开始使用及必要限制，实际输出如下：

打开 Maple，点击“新建项目”，选择一个空文件夹，就能开始记录。旧笔记仍在原位置，不会自动出现在新项目中。

自动备份可按需开启，目前尚未启用。进入“设置 → 备份”，选择备份目标文件夹，再打开“自动备份”。首次看到“备份成功”后，才能确认已有副本；仅安装好并不代表已备份。自动备份尚未用真实项目验证。

请保留安装时生成的 maple-receipt.json 文件。需要恢复原设置时，进入“设置 → 高级 → 恢复原设置”，选择该文件，先点“预览”，确认后再点“恢复”。这只会恢复配置，不会删除项目文件，也不会自动迁移旧笔记。

备份未验证、首次成功才算有副本、恢复需要原记录等限制没有被删掉。与操作无关的维护细节没有进入使用说明。
